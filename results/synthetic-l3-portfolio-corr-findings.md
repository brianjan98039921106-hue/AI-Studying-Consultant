# V-C4-2：錄取相關時，獨立模型錯多少 結論（W-29）

> 原始數據：[synthetic-l3-portfolio-corr.md](synthetic-l3-portfolio-corr.md)。預先登記：`scripts/run_l3_portfolio_corr.py` 檔頭（執行前已推上 GitHub）。
> 設定：C4.2 單因子 Gaussian copula（A-C4-5）；2 種合成情境（分層：夢幻／目標／保底；均勻：機率與效用無關）× 學校數 10、20 × 申請數 3、6，每格 100 個情境；真實 ρ = 0、0.2、0.4、0.6、0.8。最佳化與評估用不同的模擬抽樣。
> **限制**：錄取機率與效用都是合成值（C3 未完成）；真實的 ρ 未知，0.4 是事先指定的「中度相關」。

## 1. 預先登記判定

| 規則 | 內容 | 結果 |
|---|---|---|
| D1 回報值 | ρ = 0.4 時任一格高估 > 10% → 期望效用改用 C4.2 報 ρ 範圍 | ❌ 未觸發（最高 9.8%） |
| D2 選擇 a | 每種情境至少一格，C4.1 組合在 ρ = 0.4 的遺憾 > 1% 且 > 2 SE | ❌（分層 ✅ 1.1%；均勻最高 0.4%） |
| D2 選擇 b | 實際獨立（ρ = 0）時，改用 ρ = 0.4 組合的代價 ≤ 0.5% | ❌（最高 1.2%） |
| D2 選擇 c | 實際 ρ = 0.8 時，ρ = 0.4 組合的遺憾低於 C4.1 組合 | ✅ 8／8 格 |

依預先登記：**預設仍是 C4.1 的選擇與期望效用**；C4.2 為可選用。

## 2. 結論

| # | 結論 | 證據 | 等級 |
|---|---|---|---|
| F109 | **獨立模型高估期望效用**，ρ 越高越嚴重（分層情境中申請越多也越嚴重；均勻情境不一定）：ρ = 0.4 時高估 3.1–9.8%，ρ = 0.8 時 9.1–22.6%；分層情境（夢幻校效用高）高於均勻情境 | 8 格 × 5 個 ρ | ✅（合成） |
| F110 | **但 C4.1 選出的組合幾乎不吃虧**：ρ = 0.4 時比真正最佳少 0.2–1.1%，ρ = 0.8 時最多 3.5%；C4.2 選的組合常不同（ρ = 0.4 時 27–88% 的情境），但多是效用幾乎相同的組合 | 同上 | ✅（合成） |
| F111 | 假設 ρ = 0.4 的組合在實際 ρ = 0.8 時較好（遺憾 ≤ 0.5% vs ≤ 3.5%），但實際獨立時最多少 1.2%；兩邊的代價都小，沒有一致更好的選擇 | D2 b、c | ✅（合成） |
| F112 | 錄取相關造成的主要問題是「期望效用的數字太樂觀」，不是「選錯學校」；在 C3 能估計 ρ 之前，C4 的輸出應註明獨立假設，並可用 `portfolio_value_mc` 看敏感度 | F109–F111 | 💭 推論 |

## 3. 決策

| 項目 | 決策 |
|---|---|
| 預設 | C4.1 精確解（選擇與期望效用），不變 |
| 可選用 | `aisc.portfolio.recommend_portfolio(..., rho=…)`、`admission_draws`、`portfolio_value_mc`（[USAGE §4.7](../docs/USAGE.md)） |
| B-C4-1 | 🟢：相關錄取可評估、可最佳化，由測試鎖定；預設不改的理由見 F110–F111 |
| 後續 | C3 完成後以申請結果估計 ρ（A-C4-5 可能需要依學程類型分組）；W-2A（C4.3 穩健選擇）處理機率本身的不確定 |
