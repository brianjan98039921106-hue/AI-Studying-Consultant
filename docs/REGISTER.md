# 假設與盲區登錄表 Assumption & Blind-Spot Register

- **A 項目**：方法從理論繼承的假設。假設本身不是錯，但要知道它何時不成立。
- **B 項目**：演算法盲區，即模型看不到、或會系統性出錯的地方。
- **S 項目**：系統層盲區，跨部件或來自使用情境。
- **風險**：H = 會讓推薦方向錯誤；M = 會降低品質；L = 次要。
- **狀態**：🔴 未處理 · 🟡 已有探針／指標，未修 · 🟢 已修並由測試鎖定 · ⚪ 接受（書面理由）

新增項目規則：先登錄 → 寫探針或指標 → 才修。修好時探針由 xfail 轉 pass，同一個 commit 更新狀態。
