# C3 錄取可行性

**目的**：估計 $P(\text{admit} \mid \text{學生}, \text{學程})$，並誠實表達不確定性。
**輸出契約**：`contracts.AdmitEstimate`（`mean`、`low`、`high`、`method`）——下游必須使用區間。
**原則**：C3 完成前，任何地方使用的錄取機率都必須以 `AdmitEstimate(method="assumed")` 明確標示為假設值。

## 子部件

| ID | 功能 | 方法 |
|---|---|---|
| C3.1 | 資料與偏誤稽核 | 來源：GradCafe（需先確認服務條款）、顧問歷史案例、官方公布的錄取率；稽核各來源的回報機制與台灣申請者比例 |
| C3.2 | 模型 | 階層貝氏 logistic：學程層級隨機效果（資料少的學程向同 CIP 群組收縮）＋學生特徵；以官方錄取率作為先驗錨點校正自願回報偏誤 |
| C3.3 | 校準 | 留出集 Brier score、reliability curve、區間涵蓋率；分組（台灣／國際）檢查 |

## 理論與假設
A-C3-1、A-C3-2；來源見 [THEORY](../THEORY.md#c3-錄取可行性)。

## 盲區
B-C3-1 自願回報偏誤 · B-C3-2 台灣申請者代表性不足 · B-C3-3 年度波動 · B-C3-4 未校準 · B-C3-5 不可觀測因素
