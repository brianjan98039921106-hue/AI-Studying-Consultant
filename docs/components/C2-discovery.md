# C2 探索推薦

**目的**：推薦**契合**且學生**原本不知道**的學程，並說明理由。
**輸入**：`StudentProfile`、`Program` 清單 **輸出契約**：`contracts.Recommendation`（含 `contributions`）

## 子部件

| ID | 功能 | v0（已實作） | v1（規劃） | 修的盲區 |
|---|---|---|---|---|
| C2.1 | 契合度 | cosine | 考慮強度的距離：例如 $1 - \lVert W^{1/2}(\hat w - x_p)\rVert / \sqrt{d}$，或 cosine × 強度懲罰；用不確定性加權 | B-C2-3 |
| C2.2 | 新穎度 | CIP 標籤距離；熟悉學程 = 0 | $P(\text{學生不知道 } p)$：由 C1.4 熟悉度 + 標籤距離 + 學程知名度估計 | B-C2-1 |
| C2.3 | 重排序 | 線性加權 + MMR（**L3 否決**，保留為參考） | ✅ **分區呈現**（`sectioned.py`）：依契合排序 → 短名單做熟悉度問答（C1.4）→ 分成「可能沒想過」與「已知且適合」兩區，不以分數懲罰已知學程 | B-C2-2 ✅、B-C2-4 |
| C2.4 | 推薦理由 | 點積精確分解 | 每換一個計分器都必須重做忠實性性質測試 | B-C2-6 |

**每個 v1 都保留 v0 作為參考實作（D8）**：消融時可直接比較「只換 C2.1」或「只換 C2.2」的效果。

## 理論與假設
A-C2-1 … A-C2-4；來源見 [THEORY](../THEORY.md#c2-探索推薦)。

## 盲區
**B-C2-1 分類距離≠不知道** · **B-C2-2 新穎度擠掉最佳契合（探針失敗中）** · **B-C2-3 cosine 忽略強度（探針失敗中）** · B-C2-4 熱門度偏誤 · B-C2-5 選擇過載 · B-C2-6 理由忠實性

## 驗證
| 層級 | 內容 | 指標 |
|---|---|---|
| L2 | 單元、理由分解性質測試、限制條件 | ✅ `test_c2_discovery.py` |

**基準（baseline）**：(a) 只推薦熱門／高排名學程；(b) 只推薦與錨點最相似的學程。C2 必須同時勝過兩者，才代表它真的在「探索」而不是換個方式推薦熱門或相似。
