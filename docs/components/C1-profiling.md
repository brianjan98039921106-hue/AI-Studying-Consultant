# C1 學生側寫

**目的**：在學生**說不出 program 名稱**的情況下，估計他的需求向量 $w$ 與不確定性 $\sigma$，以及他已經知道哪些學程。
**輸入**：問卷回答、錨點（已知想讀的學程）、熟悉度回答
**輸出契約**：`contracts.StudentProfile`（`needs`、`uncertainty`、`anchors`、`familiar`、`hard_constraints`）

**設計重點**
- **偏好是在提問中建構的**（Payne et al. 1992）：側寫是一個快照，必須回報穩定度，不能當成學生的「真實本質」。
- **資訊價值選題**：問的目的不是把每個維度都測準，而是把**會影響推薦結果**的維度測準。這是和一般心理測驗最大的差別。
