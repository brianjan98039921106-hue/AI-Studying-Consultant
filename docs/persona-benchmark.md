# 人物設定基準：盲評（W-80）

> 給評分者（你，以及一位獨立的顧問）。評估計畫見 [evaluation-plan.md](evaluation-plan.md) §2；判準寫在 `scripts/run_persona_benchmark.py` 檔頭（預先登記 v2）。人物是虛構的（`data/benchmark/personas.json`，`"synthetic": true`）。

## 0. 做法（TREC 式彙集評分）

| 步驟 | 內容 | 為什麼 |
|---|---|---|
| 1 | 每個人物，把模型、B1 熱門、B2 只看興趣三種做法的前 10 名合在一起，再加 5 個隨機學門，打亂順序（`data/benchmark/pool.json`，每人 25–35 個） | 評分者看不出哪個學門來自哪個做法，就不會不自覺偏向模型；隨機學門用來看評分寬嚴 |
| 2 | 評分者先寫下 2–3 個「一定要出現」的學門，**鎖定後**才看到評分清單 | 補上「該出現卻沒出現」（召回）；鎖定是為了不被清單影響 |
| 3 | 每個學門評 0 不適合、1 可以、2 很適合；清單維持打亂的順序，每頁 8 個 | 比從 863 個學門裡自己列答案快很多，也比較一致 |
| 4 | 評完按「複製評分結果」交回，我存成 `data/benchmark/judgments_<評分者>.txt` 並提交，之後才計分 | 預先登記：腳本拒絕計分沒提交或之後改過的評分 |

**為什麼評分清單不依大類分組（v2.1，2026-10-31，任何評分之前）**：分組比較好找，但模型的前 10 名常集中在少數大類。實測 16 個人物的評分池：模型推薦的學門所在的大類，池中平均有 9.9 個學門；其他學門所在的大類平均只有 4.7 個（每人 7–14 個大類）。分組後「最大的那幾組」幾乎就是模型推的，盲評就失效了（F190）。所以改成分頁：順序仍是打亂的，每頁 8 個、每人 4–5 頁，每個學門下方仍標示大類。

## 1. 最重要的規則

| 規則 | 原因 |
|---|---|
| **評完以前，不要用這些人物去試推薦網頁或模型** | 看過結果再評，就只是在測「模型像不像它自己」（A-C2-61） |
| 顧問自己評，**不要看你的評分** | 才能比對兩人的判斷一致到什麼程度 |
| 只看學門本身適不適合這位學生，不考慮學校、排名或錄取難度 | 錄取可行性不在這次範圍（D13） |
| 已交回的評分想修改：重新複製一次交回（後交的取代先交的同一人物），並說明理由 | 可追溯 |

## 3. 評分網頁

評分網頁由 `python scripts/run_persona_benchmark.py --build-page <輸出檔>` 產生（原始檔 `web/judge.html`，資料全部內嵌、不連外）。

| 項目 | 說明 |
|---|---|
| 選擇身分 | Brian：P01–P16；顧問：P02（同領域）、P06（相鄰）、P09（遠距）、P13（多學位）；其他評分者：全部 |
| 步驟 1 | 先選大類（CIP 2 碼，35 類，中文名稱），再勾 2–3 個一定要出現的學位；也可以輸入英文關鍵字或 CIP 代碼跨大類搜尋。按「鎖定，開始評分」。換人物時大類與搜尋會清空，避免沿用上一位的方向 |
| 步驟 2 | 每頁 8 個學門（打亂順序，不分組），點 0／1／2；用「上一頁／下一頁」切換，畫面顯示這位人物還剩幾個沒評，最後一頁是「下一位人物」 |
| 交回 | 「複製評分結果」只包含已評完的人物，可以分次交；文字以 `AISC-JUDGMENTS v1` 開頭、`END` 結尾 |
| 進度 | 只存在這個瀏覽器；換電腦或清除瀏覽資料會不見，評完記得複製 |

## 4. 分數怎麼算（摘要）

| 指標 | 意思 |
|---|---|
| nDCG@10（主要） | 「你可能沒想過」前 10 名的排序品質（2 分學門 3 倍、1 分學門 1 倍，前面名次權重較高；1 = 和評分者最理想的排序一樣） |
| Hit@10 | 前 10 名至少有 1 個評 2 分的學門 |
| 評 0 分個數 | 前 10 名中評「不適合」的個數（明顯錯誤） |
| 一定要出現的命中率 | 一定要出現的學門有幾成進了模型前 10 名 |
| 隨機學門平均分 | 評分寬嚴：≥ 1 表示可能評得太寬 |
| 評分者一致性 | 兩人都評的人物：加權 κ（−1～1，越高越一致）、完全一致比例、一定要出現的重疊 |

判準（只用 Brian 的評分判定；顧問的評分重算一次只報告）：

| 判準 | 門檻 |
|---|---|
| 模型平均 nDCG@10 − B1 熱門 | ≥ 0.20 |
| 模型平均 nDCG@10 − B2 只看興趣 | ≥ 0 |
| Hit@10 | ≥ 90% 的人物 |
| 前 10 名評 0 分的平均個數 | ≤ 2 |
| 一定要出現的平均命中率 | ≥ 50% |
| 退步（之後每次改模型，CI） | 平均 nDCG@10 下降 > 0.05，或模型前 10 名中已評分的比例 < 90%（要先把新學門加進評分池並評分） |

執行：`python scripts/run_persona_benchmark.py --score --second consultant` → `results/persona-benchmark.md`。
