# 全背景擴充規格 All-Backgrounds Specification

> 決策（2026-10-27）：**系統服務所有台灣申請者，不限就學背景**；推薦也不限領域（例如材料 → 牙醫 → 設計）。
> 本文件只描述設計、限制、各階段的解決方案與擬合方式。狀態一律記在單一來源：盲區與假設 → [REGISTER](REGISTER.md)、工項 → [ROADMAP](ROADMAP.md) Phase 6、關卡 → [VALIDATION](VALIDATION.md) §5。

## 1. 「所有學生」的定義

| 面向 | 涵蓋 | 對系統的含意 |
|---|---|---|
| 學科背景 | 所有領域（理工、醫藥衛生、人文藝術、社會科學、商管、教育、農業……） | 需求維度、條件類別、模擬器都不能預設背景 |
| 學制與學歷 | 一般大學、科技大學、專科＋二技、學士後、境外學歷、已有碩博士或專業學位 | 學歷等值是一種條件（B-C6-5）；可以有多個學位 |
| 人生階段 | 應屆、工作數年、轉換跑道、二度進修 | 興趣先驗可能過時（B-C1-7）；錨點可能屬於舊領域（B-C1-22）；不假設申請時間（D9） |
| 目標學位 | 碩士、研究型博士、專業學位（DDS、MD、JD 等）、學士後證書 | 目錄須含其他學位層級（B-C0-10）；研究型博士的契合另需指導教授資訊（B-C0-12） |

## 2. 新增設計原則

| ID | 原則 | 落實方式 |
|---|---|---|
| D10（擴大） | **結構與領域無關；資料範圍分版擴充，但產品目標是全領域** | `mvp_scope.json` 只是上線階段（v1 商管 × 數據 × 工程管理 → v2 相鄰領域與其他學位層級 → v3 全領域），不是產品限制 |
| D11 | **測量對所有背景等值** | 同一題對不同背景的學生要測到同一件事；以測量恆等性與 DIF 檢驗（V-C1-9）；不通過的題目改寫或移除 |
| D12 | **評估看最差的群體，不只看平均** | 所有 L3／L5 指標依背景分層報告；選方法時用「最差層」作為準則（延伸 F37 的 maximin）；任一層未達門檻，該層標示為「尚未支援」 |

## 3. 各部件的限制、解決方案與擬合方式

| 部件 | 全背景下的限制（盲區） | 解決方案 | 擬合方式（參數怎麼決定） | 驗證 |
|---|---|---|---|---|
| C0 目錄 | 只收商管 × 數據碩士（B-C0-6、B-C0-10）；評分準則的錨點以商管例子寫成（B-C0-11）；研究型博士看指導教授（B-C0-12）；黃金標準只在部分領域（B-C0-13）；教職稀釋在人文領域更嚴重（B-C0-8） | 範圍三階段擴充；評分準則改寫為活動導向錨點，並補各領域例子；研究型博士另建「研究主題 × 指導教授」層（v3 之後）；黃金標準依 2 碼 CIP 族群分層抽樣 | 職業橋接 v2 以 BLS OEWS 就業人數加權（沒有自由參數）；擷取提示與評分準則在部分族群開發，**留一族群外推**（leave-one-family-out）檢驗 | V-C0-6 評分準則跨領域一致性；C0.4 收斂效度依族群報告 |
| C1 側寫 | 領域層偏向 MVP（B-C1-19）；題目情境偏向某些背景（B-C1-20）；維度變多使作答負擔上升（B-C1-21）；轉換者錨點來自舊領域（B-C1-22）；高中興趣分數只適用部分學生（B-C1-7） | 領域層改為跨領域分類（候選：O\*NET 細分興趣領域，W-64）；**兩階段提問**：先問 RIASEC 與大領域群，再只深入相關子領域；題目改寫為不依賴背景知識的活動描述；錨點加問「這是過去的領域還是想去的領域」 | 領域層結構：W-41 資料分半，一半探索性因素分析、一半驗證性因素分析；題目參數：等級反應模型（graded response）校準；兩階段提問的切換規則：L3 預先登記（原型挑選、連續驗證、新種子確認，並含轉換者情境） | V-C1-9 測量恆等性；V-C1-2 τ 依背景分層；V-C1-3 題數依背景分層 |
| C2 推薦 | 遠領域假陽性：只因興趣層相似就推薦遠領域學程（B-C2-8）；大目錄下短名單集中於熱門或單一領域（B-C2-9） | 領域層權重納入計分器選擇；短名單加入領域多樣性（MMR 以 CIP 族群為多樣性單位）；遠領域推薦附「為什麼相關」的理由 | 計分器與多樣性參數：maximin 同時跨真相函數與背景層（D12），預先登記 | V-C2-8 遠領域假陽性率（L5）；V-C2-4 覆蓋率依族群 |
| C3 錄取 | 錄取流程異質：集中申請系統、面試、作品集審查（B-C3-6）；稀有領域資料稀疏（B-C3-7） | 依學程類型分模型；稀疏領域向同族群收縮；沒有足夠資料時只輸出 `method="assumed"` 的寬區間 | 階層貝氏：學程類型 × CIP 族群部分合併；以官方錄取率為先驗；分層校準 | V-C3-3／4 依學程類型與背景分層 |
| C4 組合 | 不同學位類型的申請成本與時程差異大（B-C4-6） | 成本由學生輸入或官網費用；時程只在申請模式考慮 | 無自由參數（成本為輸入） | V-C4-1 不變 |
| C5 模擬 | 只有單一背景、沒有轉換者（B-C5-6）；合成目錄只有商管型原型（B-C5-7）；背景分布是猜的（B-C5-2） | 生成器加入全領域原型、多學位與轉換者；背景分布以教育部大專畢業生學門統計校準 | 背景比例：直接取官方統計（沒有自由參數）；其餘參數維持「一個生成模型挑選、另一個驗證、新種子確認」 | 所有 L3 結論加做背景分層 |
| C6 條件 | 類別表覆蓋不足（B-C6-4）；學歷等值（B-C6-5） | 類別表 draft-1 擴充到各領域（試演、LSAT、執照考試、教師證、學歷等值等）；學歷等值依學程官網規定的認證方式 | 不擬合參數；以覆蓋率稽核決定是否新增類別：黃金標準中無法對應的條件比例 | V-C6-4 各族群「無法判斷」比例 ≤ 10% |
| 系統 | 規模與成本（S-7）；評估被多數群體主導（S-8） | 分階段擴充，每階段先過關卡再擴大；招募與黃金標準設各層最低人數 | — | V-S-4 最差層指標 |

## 4. 階段計畫

| 階段 | 目標 | 前提 | 工項（ROADMAP Phase 6） | 通過條件 |
|---|---|---|---|---|
| E0 結構通用化 | 不需新資料，先把會鎖死在商管的結構改掉 | — | W-63、W-64、W-66、W-67、W-68、W-69 | 生成器含全領域與轉換者；分層評估工具可用；領域層方案通過 G0；類別表 draft-1 |
| E1 資料擴充 | 目錄從 v1 擴到 v2、v3 | E0；官方檔案 | W-65、W-70、W-71、W-72 | 每個新族群都有參考表與職業剖面；評分準則跨領域一致性（V-C0-6） |
| E2 實證 | 用真實學生確認測量對所有背景等值 | E0；W-40 招募 | W-41（分層）、W-73 | V-C1-9 測量恆等性；各層 τ 與題數 |
| E3 錄取與組合（已移到 ROADMAP Phase 7 未來擴充） | 依學程類型處理錄取與申請成本 | E1、E2 | W-44（擴充）、W-74 | V-C3-3／4 依類型分層 |

**順序的理由**：E0 改的是結構（維度、契約、模擬器、評估方式）。結構越晚改，已累積的資料與結果越多、代價越高；資料擴充（E1）則可以分批進行、隨時停下。
