# 需求維度與評分準則 v1

> 狀態：**已確認（2026-10-25）並完成程式遷移（W-16b）**。Q1–Q4 皆依建議採用；實證效度待 V-C1-5/6/7（W-41）。
> 本文件同時定義：(1) 學生端怎麼測，(2) 學程端怎麼評分。兩端必須在同一個空間，C2 才能比較。

## 1. 設計原則

| 原則 | 說明 |
|---|---|
| 分層 | 「喜歡做什麼」（興趣）、「要多深」（強度）、「在哪個領域」（領域）、「走哪條路」（取向）是不同問題，分開測量以減少重疊 |
| 有理論的維度優先 | 興趣層直接採用 RIASEC，可同時接上 O*NET（學程端）與大考中心興趣量表（學生端） |
| 學生端不出現學程名稱 | 所有題目以情境、活動、課程內容描述，避免學生只能依名稱判斷 |
| 學程端每個分數都要有證據 | 必須附官網原文片段與網址（`source_url`、`retrieved_at`） |
| 強度測「想要」，不測「能力」 | 能力不混進需求（B-C1-8）：明示先修由 C6 以差距呈現、不過濾；隱性競爭力屬 C3（D9） |

## 3. 學生端測量

| 層 | 方法 | 範例（草案） | 備註 |
|---|---|---|---|
| 興趣 | 若學生提供大考中心興趣量表的六型分數（0–99），換算為 [0, 1] 作為先驗；否則用短題 | 「整理大量資料並找出規律」喜歡程度 1–5 | 高中時測量，可能已過時：不確定性依年數放大（B-C1-7） |
| 強度 | 行為錨定：以具體課程內容描述程度 | 「你願意每週花在數學證明上的時間？」選項附具體例子：僅會用統計軟體 / 迴歸與最佳化應用 / 機率論與證明 | 問「想要」不是「能不能」 |
| 領域 | 成對情境選擇 | 「兩份工作，你比較想做哪個？A：為銀行建立信用風險模型；B：為電商規劃倉儲與配送路線」 | 成對比較可減少默許傾向（B-C1-3、A-C1-2） |
| 取向 | 情境題 | 「畢業後三年，你最想在哪裡？研究機構攻讀博士 / 大公司 / 自己的新創」 | — |

所有題目需經過回譯與 5–8 位台灣申請者的認知訪談（W-41），確認理解方式一致。

## 4. 學程端評分準則（C0.3）

> **v2 範圍（2026-10-28 修訂，B-C0-19）：** 產品目標維度是 v2（51 維）。v2 的興趣（RIASEC）與 41 個領域由 C0.2 職業橋接提供，**學程端評分只需要 4 個維度**：數理強度、程式強度、研究取向、創業取向。下表的 5 個 v1 領域維度保留給 v1 參考實作。W-21 前導 v0 用的是修訂前的版本，W-20 完成後要依修訂版重新擷取。

每個維度以 0 / 0.25 / 0.5 / 0.75 / 1 評分。

### 4.1 錨點（v2 的 4 個維度）

| 維度 | 0 | 0.25 | 0.5 | 0.75 | 1 |
|---|---|---|---|---|---|
| `quant_intensity` | 完整必修課表中沒有統計或數學課 | 必修入門統計、研究方法或資料分析課，但沒有建模 | 必修應用層級的迴歸、最佳化或統計建模 | 必修隨機過程、金融數學等進階課，但課程描述看不出需要證明 | 必修機率論、數學最佳化等需證明的課程 |
| `programming_intensity` | 完整必修課表中沒有程式課 | 必修課使用試算表或套裝軟體做分析，但不寫程式 | 一門必修程式或資料課（Python、R、SQL） | 兩門必修程式或資料課 | 多門必修軟體或系統課，或以工程實作為主的畢業專題 |
| `research_orientation` | 沒有論文、研究或畢業專題要求 | 必修**非研究型**畢業作品：創作（小說、影片、演奏會、展覽）或實務專案（顧問案、專業計畫） | 論文或研究專題**可選**；或必修研究論文以外的研究型報告 | 必修研究專題或研究報告，但不是論文 | 必修研究論文；或此碩士本身就是博士學程的一段（例如只在博士途中授予） |
| `entrepreneurship` | 官網與校級資源頁都沒有創業資源 | 只有學生社團或活動（競賽、講座） | 有創業選修課，或校級加速器／育成中心開放本學程學生申請 | 必修一門創業課 | 課程內建創業專案或育成流程（真實創業，不是模擬） |

### 4.2 證據規則

| 情況 | 規則 |
|---|---|
| 一般分數 | 附官網原文片段（建議 ≤ 15 個英文字）與網址；行銷用語（「頂尖」「業界領先」）不得作為證據（B-C0-3） |
| **0 分（「沒有」）** | 證據是**完整必修課表或畢業要求頁的網址**，證據類型記為「缺項」；引文寫課表標題即可 |
| 課表不完整 | 頁面只列部分課程（「courses may include」「sample curriculum」）而找不到完整課表時，記為**缺值**，不給 0 |
| 創作型或實務型畢業作品 | 研究取向最多 0.25，即使頁面稱為 thesis（MFA 論文、論文影片、畢業演奏） |
| 博士銜接 | 只有「此碩士本身是博士學程的一段」才算 1；學校另有雙學位（例如 MD/PhD）不提高本學程分數 |
| 創業取向 | 必須同時看學程頁與該校創業中心或育成中心頁；只看學程頁就記缺值 |
| 頁面年份 | 用最新學年的課程目錄；只能找到 3 年以前的版本時可以用，但在備註寫年份（B-C0-5） |
| 同一學位多個方向 | 評分依「主要或預設方向」；備註寫採用了哪個方向 |
| 固定頁面 | W-20 兩位評分者評同一組頁面（[w21-pilot.md](w21-pilot.md) 的 `program_url`、`urls_fetched`）；需要時可再開同校其他官網頁，但要記下網址 |

### 4.3 評分流程

| 步驟 | 內容 |
|---|---|
| 1 | 每個分數附證據（4.2）；無證據 → 缺值，不猜 |
| 2 | 兩位評分者獨立評分 30 個黃金標準學程（W-20），彼此不看對方與 W-21 的分數 |
| 3 | 以加權 κ（二次權重）計算一致性；κ < 0.7 的維度修訂錨點後重評 |
| 4 | 差距 ≥ 0.5 的個案由第三人裁決，裁決理由寫入資料 |
| 5 | 黃金標準確定後，計算 W-21 擷取的一致率（V-C0-2，門檻 90%：差距 ≤ 0.25 視為一致） |

### 4.4 v1 參考：領域維度（只用於 v1）

| 維度 | 0 | 0.5 | 1 | 主要證據 |
|---|---|---|---|---|
| `domain_finance` | 沒有金融課程 | 有金融專長或選修模組 | 核心課程以金融為主 | 課程結構、就業報告的產業分布 |
| `domain_tech_product` | 沒有 | 有科技產業選修或就業比例明顯 | 核心課程以科技產品或工程管理為主 | 同上 |
| `domain_operations` | 沒有 | 有營運／供應鏈選修 | 核心課程以營運、供應鏈、製造系統為主 | 同上 |
| `domain_design` | 沒有 | 有設計或使用者經驗選修 | 以工作室（studio）形式的設計核心課程 | 課程結構、作品集要求 |
| `domain_policy_social` | 沒有 | 有政策或社會議題選修 | 核心課程以公共政策為主 | 同上 |
| `riasec_*` | 不在此評分；由 C0.2 從 O*NET 職業興趣剖面推導 | — | — | C0.3 可另外估計，作為 C0.4 交叉比對 |
