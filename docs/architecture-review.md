# 部件演算法架構檢討：統計、機器學習與深度學習的選項（2026-10-28）

> 目的：逐一檢視 C0–C6 是否有更精準、更有效率、更適合產出目標的演算法，**包括機器學習與深度學習**。
> 產出目標（ARCHITECTURE §1）：依需求而非學程名稱側寫學生（D1），推薦「相關且不知道」的學程（D7），所有背景都要可靠（D10–D12），推薦理由要精確可解釋（B-C2-6），能力不得影響推薦（D9）。
> 判斷依據：本專案已有的證據（F 編號）、各方法的資料需求，以及目前**沒有任何真實學生標註資料**這個事實。
> 本文件是規劃；每個被採用的方法仍須先過 G0（THEORY ＋ REGISTER），再依 VALIDATION 的階梯驗證。

## 0. 總結

| 結論 | 依據 | 等級 |
|---|---|---|
| **最大的誤差來源是 C1 測量，不是排序演算法**：問了 45 題後，推薦品質仍比理論上限低 0.12–0.22（F32）；題目雜訊的影響遠大於選題策略（F26）；作答比例是最大槓桿（F23）；計分器之間的差異很小（F37：−0.002～+0.011） | 已確認（L3） | 因此改進優先投在 C1 與 C0 的「測量」，不是 C2 換更複雜的排序模型 |
| **深度學習目前沒有可用的訓練資料**：推薦類深度模型（雙塔、序列模型）需要大量互動紀錄；本產品是冷啟動、每位學生只用一次、真實樣本預計 200 人（study-protocol） | 推論 | 現階段不建議以深度學習取代 C1–C2 的核心 |
| **深度學習最適合的位置是「文字轉成向量」**：C0.3 課程擷取（學程官網 → 41 領域等屬性）、C6 條件擷取、學生自由敘述轉成需求先驗。這些可以用預訓練模型（大型語言模型、多語句向量），不需要本專案自己的標註資料 | 推論；需 W-20 黃金標準驗證 | 列為 C0.3、C6、C1 的候選 |
| **有了 W-41／W-76 資料後，最適合的機器學習是「偏好學習」**：成對選擇的階層貝氏條件 logit，等同 learning-to-rank 的 pairwise 損失，但參數少、可解釋、可在 200 人規模估計 | 推論 | W-76 之後 |
| 可以**現在**就做、而且能用真實資料檢驗的改進：以 O\*NET 職業資料學到的**領域相關結構**補全學生未作答的領域（取代手設的領域群先驗） | 推論；本次以真實資料預先登記檢驗（§2.1） | 立即採用候選 |

## 1. 逐部件檢討

### C0 Program 知識庫

| 項目 | 內容 |
|---|---|
| 現況 | CIP → SOC → O\*NET 等權平均（v1）；非學術剖面排除教職（F97–F98）；就業加權已建但不採用（F102–F104） |
| 已知問題 | 同一 CIP 的學程完全相同（B-C0-1）；「其他」代碼沒有剖面（B-C0-9、F95）；強度與取向沒有官方來源，要靠 C0.3 |
| 候選 A：語言模型擷取課程（W-21） | 從學程官網的課程清單與說明，抽出強度、取向，並把課程描述對應到 O\*NET 的代表活動與工作任務（每個領域有官方活動描述，已在題庫中核對，見 item-bank-v2）。可用大型語言模型的結構化輸出，或多語句向量模型（Reimers & Gurevych, 2019）算課程與活動描述的相似度 |
| 候選 B：貝氏融合 | 以職業剖面作先驗、課程證據作觀測，做階層收縮（同 CIP 的學程向共同先驗收縮，證據多的學程偏離較多）；同時解決 B-C0-1 與 B-C0-9，並保留不確定性（D4） |
| 評估 | 候選 A 是深度學習在本專案最有價值的位置（不需要自己的訓練資料）；但必須用 W-20 黃金標準檢查擷取正確率（V-C0-2 ≥ 90%）。本環境無法下載預訓練模型，只能先完成設計與融合數學 |
| 建議 | **採用 A＋B 作為 C0.3／C0.4 的方向**；先做 B 的數學與 L2（不依賴模型），A 待可用的模型 API 與 W-20 |

### C1 學生側寫

| 項目 | 內容 |
|---|---|
| 現況 | 陳述題 ＋ 錨點先驗（C1.2 v1）＋ 高斯自適應選題（C1.3 v1）；v2 未作答領域用領域群先驗 |
| 已知問題 | 測量是最大損失（F32）；自適應只省 13–28% 題目（F24）；可校準的雜訊模型反而傷排序（F43–F46）；v2 有 41 個領域，作答負擔高（B-C1-21） |
| 候選 A：相關結構補全（立即） | 41 個領域彼此相關（例如醫學與生命科學）。用多變量常態的條件期望 E[未答 ｜ 已答]，相關矩陣先從 O\*NET 職業興趣剖面估計，之後改用 W-41 學生資料。比「群分數＝群內每個領域」的手設先驗更有根據，也能讓自適應選題利用相關性（問一題能更新多個維度） |
| 候選 B：項目反應理論（W-41 後） | 等級反應模型（Samejima, 1969）把 5 點作答當作有序類別，**直接處理上下限截斷**（SIMEX 失敗的原因之一，B-C2-14）；多維 IRT 加電腦化適性測驗（以 Fisher 資訊選題）是成熟做法，可取代目前的高斯近似 |
| 候選 C：自由敘述轉向量（深度學習） | 學生用一段話描述想做的事，以句向量或語言模型對應到 41 領域的官方活動描述，作為先驗；可大幅減少題數。風險：不同背景的寫作方式不同（D11），需 W-41 驗證 |
| 評估 | A 可以現在用真實 O\*NET 資料檢驗；B 需要 W-41 作答資料校準題目參數；C 需要可用模型與 W-41 |
| 建議 | **立即採用 A（若通過 §2.1 的預先登記檢驗）**；B 列入 W-41／W-73；C 列為 W-41 的附加題 |

### C2 探索推薦

| 項目 | 內容 |
|---|---|
| 現況 | blend(0.25) 計分（F37）；熟悉度確認後分區（F11–F15）；v2 計分器與領域把關都未通過（F71、F77、F81） |
| 已知問題 | 計分器之間差異很小，結論取決於真實層權重（B-C5-8）；大目錄下短名單可能被單一領域占滿（B-C2-9） |
| 候選 A：偏好學習排序 | 以 W-76 的成對選擇資料學習每層（或每維）權重：階層貝氏條件 logit；本質是 pairwise learning-to-rank（Rendle et al., 2009 的 BPR 同類損失），但參數少、可解釋、200 人可估 |
| 候選 B：深度推薦模型（雙塔、序列模型） | 需要大量學生 × 學程互動資料；本產品冷啟動且每人只用一次，**不適合** |
| 候選 C：探索與利用（上線後） | 以 Thompson sampling 在「相關且不知道」的候選中分配曝光（Chapelle & Li, 2011），從學生的「有興趣／沒興趣」回饋學習；需要上線後的回饋資料 |
| 候選 D：短名單多樣化 | MMR 已實作於 v0（C2.3）；在分區流程的短名單加入族群多樣性，處理 B-C2-9；可在模擬中預先登記檢驗 |
| 評估 | 排序端的主要不確定性是層權重（真實資料問題），不是模型容量 |
| 建議 | **不換深度模型**；A 在 W-76 後；D 可在模擬中先做 |

## 2. 本次立即採用的項目

### 2.1 C1：以相關結構補全未作答的領域

| 項目 | 內容 |
|---|---|
| 方法 | 多變量常態條件期望：μ_U + Σ_UA Σ_AA⁻¹ (y_A − μ_A)，μ 與 Σ 由 O\*NET 職業的 41 領域剖面估計（加上收縮以穩定逆矩陣）；第一層群分數也作為觀測（群分數 ≈ 群內主要領域的最大值，近似為平均的觀測） |
| 檢驗（預先登記） | 以 O\*NET 職業作為「已知完整剖面」：交叉驗證中只「回答」部分領域，比較各方法對未答領域的預測誤差與排序 |
| 限制 | 職業的領域結構不一定等於學生的興趣結構；這是 W-41 前的暫時證據 |

結果（[F105–F107](../results/interest-area-imputation-findings.md)）：相關補全在 6 個設定都大幅降低未答領域的誤差（RMSE −0.029～−0.112），答得越少好處越大；但「雜訊 0、細問 3 群」時前 5 名找回率略低，依預先登記**不改預設**，改為可選用的 `area_model="correlated"`，待 W-41 學生資料再檢驗。

### 2.2 C1：以相關結構自適應選擇細問的領域

| 項目 | 內容 |
|---|---|
| 方法 | 沿用 §2.1 的聯合常態模型，每答一題就更新所有領域；比較 A 最適（總後驗變異數下降最多）與上信賴界（後驗平均＋標準差最大）兩種選題，對照兩階段順序 |
| 結果（[F113–F116](../results/interest-area-adaptive-findings.md)） | 兩種選題都**未通過**預先登記；但「兩階段＋相關補全」只細問 4 個領域，誤差就低於現行預設細問 12 個（F115）。有雜訊時已答領域直接用作答值，題數增加不再改善（F116，去雜訊為後續候選） |
