# 實測研究方案：側寫信效度 ＋ 需求層權重 ＋ 重測（W-40、W-41、W-76）

> 狀態：**草案 v0**（2026-10-27）。尚未施測、尚未收集任何真實資料。
> 目的：一次施測同時回答三個問題。(1) 題目可不可靠：W-41、V-C1-5～7、V-C1-9。(2) 真實學生判斷「契合」時各層佔多少份量：W-76，用來解開 W-16c 的 B-C5-8。(3) 作答誤差多大：SIMEX 校正需要，見 F86、F90。
> 依據：[layer-weights.md](layer-weights.md)、[F85–F90](../results/FINDINGS.md)、CONTRIBUTING.md「Personal data」。

## 1. 研究設計總覽

| 階段 | 對象 | 內容 | 時間 | 回答的問題 |

| 選做 C | 2–3 位顧問 | 對部分學生的學程清單評分 | — | 與學生判斷交叉比對（B-C2-13） |

## 2. 樣本

| 項目 | 設計 | 理由 |
|---|---|---|
| 總人數 | 200 人 | 參數還原：200 人 × 20 組時，兩種模擬真相能 100% 區分（F85） |
| 分層 | 四種背景各 ≥ 40 人：同領域延續、相鄰轉換、遠距轉換、多學位 | D12：結果依背景分層報告；四層人數接近時，最差層的估計才有意義 |
| 重測人數 | ≥ 60 人，四層各 ≥ 15 人 | 每題 σ 的相對標準誤約 1/√(2·59) ≈ 9%，95% 區間約 ±18%，在 F90 要求的 ±30% 內 |
| 納入條件 | 年滿 18 歲；正在考慮或規劃赴美研究所 | 排除未成年人，避免額外的同意程序 |
| 與 W-40 的差異 | W-40 原訂 10–20 位學生；W-76 需要 200 人 | **待決定**（§7） |

## 3. 工具

| 工具 | 內容 | 前置條件 |

| 成對比較 | 20 組「兩個匿名學程描述」，選較符合自己的一個，另答把握程度（1–4）；其中 4 組在 S2 重複出現 | 刺激物見下列 |
| 刺激物（學程描述） | 約 30 個真實學程。RIASEC 與 41 領域取自 C0.2 職業橋接；強度與取向取自 C0.3 評分準則（W-20 兩位評分者）。描述只寫課程內容與活動，不寫校名、排名、學費 | (a) **C0.2 參考表目前只涵蓋商管 × 數據 × 工程管理（MVP 範圍）**；刺激物必須跨領域，否則領域差異太小，估不出領域份量 → 先把參考表擴到全領域（W-65、W-70）。(b) W-20 評分準則要能評 v2 維度 |
| 背景資料 | 大學科系、學位、轉換類型自評、預計申請時間 | 分層用；不收姓名以外的識別資料（§6） |

成對組合的設計：各層的差異方向互相錯開，例如興趣相近但領域不同、領域相近但強度不同，避免共線。**刺激物定案後，要用實際的 30 個學程重跑參數還原**（目前的檢驗用 180 個模擬學程、隨機配對），確認區分力仍足夠。

## 4. 分析計畫（施測前預先登記）

| 分析 | 方法 | 判準 |
|---|---|---|
| 內部一致性 | Cronbach's α（各維度） | V-C1-5：≥ 0.7 |
| 重測信度 | 重測相關 | V-C1-6：≥ 0.7 |
| 作答誤差與信度 | 每題 σ̂ = SD(第一次 − 第二次) / √2，每題信度 = 兩次作答的相關；同層合併作為穩健版本 | 給測量誤差校正用；也檢查題目雜訊是否接近 0.30（F89：太高時校正不完全） |
| 測量恆等性 | 多群組 CFA ＋ DIF（W-73） | V-C1-9 |
| 層份量 | 成對 logit ＋ 測量誤差校正（方法待 §8 定案；SIMEX 已排除，F91–F93）；全體與各背景層 | [layer-weights.md](layer-weights.md) §4 的決策規則 |
| 選擇一致性 | S2 重複的 4 組成對比較的一致率 | 與模擬假設 0.75 比較；差很多時重跑參數還原 |
| 熟悉度回報 | 漏報率與誤報率（需要部分學程的真實熟悉度：以「描述相關問題」交叉檢查） | F12 |

**已知風險：** 重測間隔中學生的需求可能真的改變，這會讓 σ 被高估，SIMEX 因而過度校正（F90）。對策：間隔不超過 2 週；並把 σ 打 7 折作敏感度分析（F90 顯示 × 0.7 的影響較小）。

## 5. 程序

1. 招募與篩選（§2 納入條件），取得書面（電子）同意。
2. S1 線上施測，題目順序與成對比較順序隨機化。
3. 1–2 週後寄送 S2 重測邀請。
4. 資料去識別化後才進入分析；分析程式只讀 `data/private/` 中的去識別化檔案。

## 6. 倫理與個資

| 項目 | 做法 |
|---|---|
| 法規 | 個人資料保護法：告知蒐集目的、類別、利用期間與方式、當事人權利（CONTRIBUTING.md「Personal data」） |
| 同意 | 書面（電子）同意；可隨時退出並要求刪除 |
| 儲存 | 只存在 `data/private/`（已 gitignore），不進 repo；對外只發表去識別化的彙總結果 |
| 最小蒐集 | 不收身分證號、聯絡方式以外的識別資料；聯絡方式與作答分開存放，重測配對後即刪除 |
| 倫理審查 | 是否送研究倫理審查（REC）視執行單位而定：若與學校合作或要發表，通常需要 → **待決定**（§7） |
| 報酬 | 若提供，金額小且與作答內容無關 → **待決定** |
