# 需求層權重估計（W-76）

> 狀態：G0（本文件）；估計器與模擬參數還原檢驗見 §6。
> 為什麼要做：W-16c 的三次預先登記 L3（[F70–F84](../results/FINDINGS.md)）都卡在同一個未知數。v2 維度、v2 計分器、領域把關有沒有價值，取決於真實學生判斷「契合」時，興趣、強度、領域、取向各層佔多少份量（B-C5-8）。模擬只能假設這個份量，不能告訴我們它是多少。

## 1. 估計目標

| 項目 | 定義 |
|---|---|
| 契合效用 | U(s, p) = − Σ_l β_l · D_l(s, p)，D_l = 第 l 層各維度平方差的平均；β_l ≥ 0 |
| 層份量（估計目標） | π_l = β_l / Σ β，四層：興趣、強度、領域、取向 |
| 與模擬真相的對應 | 54 維等權真相 ⇔ π ∝ 每層維度數（領域約 0.80）；5 層等權真相 ⇔ 各層 0.25（不含殘差）。估計值落在哪裡，就決定 W-16c 該用哪一種真相（或估計值本身）重新選擇 |

## 2. 資料收集（併入 W-41 樣本）

| 項目 | 設計 |
|---|---|
| 受訪者 | W-41 的學生（已完成 v2 51 題問卷），依背景分層招募 |
| 作業 | 每人看 K 組「兩個學程」的描述（只描述內容與活動，不顯示校名與排名），選出較符合自己的一個；另問把握程度（可選） |
| 學程描述 | 來自真實學程（C0.3 評分準則評過的屬性）；成對組合讓各層差異互相錯開，避免某兩層的差異總是同向（共線） |
| 份量 | 預設 K = 20 組；人數依 §6 參數還原結果決定 |
| 替代來源 | 顧問對「學生 × 學程清單」評分（同一模型，改為有序 logit）；只作輔助，因為顧問的判斷可能反映自己的偏好 |

## 3. 估計方法

| 步驟 | 方法 | 來源 |
|---|---|---|
| 選擇模型 | 成對比較的條件 logit：P(選 A) = σ(U_A − U_B)，特徵為 D_l(B) − D_l(A) | Bradley & Terry (1952)；McFadden (1974) |
| 非負限制 | β_l = exp(θ_l) 重新參數化，最大概似 | — |
| 不確定性 | 以受訪者為單位的集群自助法（cluster bootstrap），報告 π_l 的 95% 區間 | Efron & Tibshirani (1993) |
| 測量誤差 | 學生側寫有作答雜訊，D_l 會被高估且各層高估程度不同（題數越多的層，平均越穩）；先以參數還原檢驗偏誤大小，偏誤超過容許值才加入 SIMEX 校正 | Cook & Stefanski (1994) |
| 分層 | 依背景層各自估計並報告最差層與全體的差異（D12）；人數不足的層併入全體 | — |

## 4. 決策規則（估計後）

| 結果 | 處理 |
|---|---|
| π 的 95% 區間只包含其中一種模擬真相的值 | 以該真相重跑 W-16c 的計分器選擇與 v1 vs v2 L3（新種子、預先登記） |
| 區間介於兩者之間 | 以估計值作為模擬真相的層權重（A-C5-13 推廣為任意權重），兩種原有真相作敏感度分析 |
| 區間太寬，兩者都無法排除 | 增加樣本或 K；不據此做 v2 決策 |

## 5. 假設與盲區

| ID | 內容 |
|---|---|
| A-C2-11 | 契合效用可以寫成各層差異的加權和（層內各維度等權、平方差） |
| A-C2-12 | 學生對學程描述的成對選擇反映他們實際申請時的契合判斷 |
| B-C2-12 | 測量誤差使 D_l 被高估，且各層程度不同，會讓層份量估計有偏 |
| B-C2-13 | 假設性選擇偏誤：看描述做選擇與真正投入申請的偏好可能不同 |

## 6. 參數還原檢驗（L3，預先登記於 `scripts/check_layer_weight_recovery.py`）

用 C5 的 v2 世界產生學生與學程；給定已知的 π，依 §3 的模型產生選擇；學生側寫加作答雜訊；再用估計器估 π。檢查偏誤、區間涵蓋率，以及需要多少人。

第一次結果（[F85–F87](../results/layer-weight-recovery-findings.md)）：200 人 × 20 組足以區分兩種模擬真相；但作答雜訊讓領域份量被高估、區間涵蓋不足（B-C2-12 成立）。下一步：加入 SIMEX 校正，W-41 加入重測以估計作答誤差。

SIMEX 結果（[F88–F90](../results/layer-weight-simex-findings.md)）：雜訊 0.15 時偏誤幾乎消除，區分力足夠；但平移區間在 1 個情境涵蓋不足，σ 給錯 30% 會明顯失準。下一步：區間改為自助法包住整個 SIMEX 流程並重驗；W-41 重測須把 σ 估到 ±30% 內。

自助法區間結果（[F91–F93](../results/layer-weight-simex-boot-findings.md)）：涵蓋率合格，但 SIMEX 點估計在「各層等權」時過度校正，且偏誤隨模擬世界變動（推測是 [0, 1] 截斷，B-C2-14）。**SIMEX 不採用。** 下一個候選是以重測估計每題信度的迴歸校正（成對特徵對學生需求是線性的）。

迴歸校正結果（[F99–F101](../results/layer-weight-rc-findings.md)）：也未通過；「各層等權」時任何估計器的領域偏誤都隨世界改變方向（B-C2-18）。但四次檢驗中，區間都能區分兩種模擬假設。**下一步**：(1) 把 W-76 的問題改為「區分領域主導與各層等權」；(2) 用實際刺激物設計配對；兩者都須新的預先登記，且要等刺激物選定（W-20）後再做，以免擬合模擬器的假設。
